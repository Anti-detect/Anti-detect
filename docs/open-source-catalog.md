# Open-source catalog

Index of **Multilogin X** and **stealth automation** resources maintained by [@multilogin-automation](https://github.com/multilogin-automation).

## Official kits

### multilogin-x-python-automation-sdk

- **Purpose:** Python client patterns for Multilogin X API (profiles, launch, session control).
- **Keywords:** `python`, `multilogin`, `browser automation`, `api sdk`
- **Repository:** https://github.com/multilogin-automation/multilogin-x-python-automation-sdk

### multilogin-x-playwright-selenium-templates

- **Purpose:** Ready-to-run **Playwright** and **Selenium** examples with stealth-oriented launch flows.
- **Keywords:** `playwright`, `selenium`, `stealth`, `anti-detect`, `headless browser`
- **Repository:** https://github.com/multilogin-automation/multilogin-x-playwright-selenium-templates

### multilogin-x-postman-api-collection

- **Purpose:** Postman collection to explore and test Multilogin X HTTP endpoints.
- **Keywords:** `postman`, `rest api`, `multilogin`, `integration`
- **Repository:** https://github.com/multilogin-automation/multilogin-x-postman-api-collection

## How to pick a kit

| Goal | Recommended kit |
|------|-----------------|
| Backend-only orchestration | Python SDK |
| UI automation with real browser control | Playwright/Selenium templates |
| API design / QA without code | Postman collection |
