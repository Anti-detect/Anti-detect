# cURL — Multilogin X Launcher

Shell examples matching Postman **cURL** tab.

| Script | Operation |
|--------|-----------|
| [start_profile.sh](start_profile.sh) | GET start profile v2 |
| [stop_profile.sh](stop_profile.sh) | GET stop profile v1 |

Requires `curl` and optional `jq` for pretty JSON.

```bash
export MLX_FOLDER_ID=...
export MLX_PROFILE_ID=...
bash start_profile.sh
```
