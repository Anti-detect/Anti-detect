# Node.js — Multilogin X Launcher

ESM examples using native **fetch** (Node 18+).

| File | Operation |
|------|-----------|
| [start_profile.mjs](start_profile.mjs) | Start saved profile |
| [stop_profile.mjs](stop_profile.mjs) | Stop profile |

```bash
export MLX_FOLDER_ID=...
export MLX_PROFILE_ID=...
node start_profile.mjs
```
